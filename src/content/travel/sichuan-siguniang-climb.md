# 四姑娘山长坪沟登山

## 行程

第一天：日隆镇 → 喇嘛寺 → 枯树滩 → 木骡子营地（3700m）

第二天：木骡子 → 水打坝 → 原路返回

## 记录

长坪沟是开发程度适中的沟，栈道尽头就是真正的山野路。傍晚在木骡子营地看幺妹峰日落，金山只持续了不到五分钟。

夜里下了雨，帐篷顶噼啪响。第二天云雾锁山，没看到峰顶，但水打坝的草甸和溪流已经很值回票价。
